MyFirstProject este un proiect demonstrativ creat pentru studierea sistemului de control al versiunilor Git și a platformei GitHub.

Scop

Scopul proiectului este de a demonstra cum pot fi organizate fișierele, urmărite modificările și păstrat istoricul dezvoltării unui proiect.

Tehnologii utilizate

Git – gestionarea versiunilor.

GitHub – găzduirea proiectului.

Markdown – documentarea proiectului.

Structura proiectului

README.md – prezentarea proiectului.

description.txt – descrierea generală.
Proiectul utilizează Git și GitHub pentru urmărirea modificărilor și păstrarea istoricului versiunilor.
plan.md – planificarea etapelor.

Autor

Proiect realizat în cadrul studiului individual.
